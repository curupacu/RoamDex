dono do projeto como inspiração de UI/UX — **não são screenshots do
RoamDex**. Sem análise escrita ainda; servem de mood board.

- `pokelike-menu.jpeg` — menu principal do Pokelike.xyz
- `pokelike-mapa-gameplay.jpeg` — mapa de rotas em árvore do Pokelike.xyz
- `referencia-tela-batalha.jpeg` — UI de batalha (jogo não identificado)
- `referencia-escolha-inicial.jpeg` — tela de escolha de inicial (jogo não identificado)
- `referencia-pokedex-colecao.jpeg` — grade de coleção/Pokédex (jogo não identificado)
